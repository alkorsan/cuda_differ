* change: character-level diff now uses InlineMyersSequenceMatcher (from myers.py) with its 3-element k-mer preprocessing, instead of a timeout-based approach. Studied WinMerge (stringdiffs.cpp: O(NP) with 500ms timeout at line 25, checked every 100000 iterations at line 678-688, fallback to whole-line at line 405-412) and VS Code (myersDiffAlgorithm.ts: O(ND) Myers with timeout check at line 46-48, algorithm selection in defaultLinesDiffComputer.ts refineDiff at line 224-226: DP for <500 chars, Myers for larger). Root cause: Myers' O(NP) algorithm and difflib's SequenceMatcher both find *an* LCS, but when multiple valid LCS of the same length exist, they may pick a different one than VS Code's DP algorithm (which uses equality scoring that prefers longer matches). * change: minimal change to myers.py (added a single super().__init__(isjunk=None, a='', b='', autojunk=False) call inside MyersSequenceMatcher.__init__) so that the inherited difflib.SequenceMatcher attributes (isjunk, autojunk, fullbcount, b2j, bjunk, bpopular) are properly initialized.
